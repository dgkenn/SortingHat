# Silver-anchor evidence review (2026-10-08)

Scope: every rule in `configs/silver_anchors.yaml`, the EEG-sentence filter (`sortinghat/labels/eeg_filter.py`) and the
banned encephalopathy codes (`sortinghat/labels/banned_evidence.py`). Citations are from PubMed (searched through the
PubMed tool, 2026-10-08); only PMIDs/DOIs actually retrieved are cited. Where no source was retrieved the row says so and
the threshold is marked **expert** (kept for the co-investigator to confirm). Principle: silver positives favour
specificity, so a rule is left unchanged when it is already stricter than the published consensus level.
No outcome or real data were used. Status: external co-I review before publication.
